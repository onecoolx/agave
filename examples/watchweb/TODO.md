# WatchWeb 功能开发计划

> 基于 touchweb 功能集，适配 480x480 圆形表盘交互

## 已完成

- [x] 网页加载/渲染 (Agave 引擎集成)
- [x] 地址栏输入
- [x] 前进/后退/刷新导航
- [x] 弧形加载进度指示

## 待开发

### P0 — 核心体验

- [ ] **滚动惯性** — 触摸拖拽滚动 + 惯性衰减动画
- [ ] **缩放手势** — 双指捏合缩放，双击放大
- [ ] **搜索引擎** — 地址栏输入非 URL 时自动搜索
- [ ] **长按菜单** — 链接/图片长按弹出操作菜单（圆形弧形菜单）

### P1 — 功能完整

- [ ] **多标签页** — 表冠旋转切换标签，边缘弧形标签指示器
- [ ] **历史记录** — SQLite 存储，列表页面（垂直滚动）
- [ ] **收藏夹** — 添加/管理收藏，快速拨号页
- [ ] **表单自动填充** — 记住用户名密码，自动填入

### P2 — 增强功能

- [ ] **设置页面** — 字体大小、缩放比例、清除数据、UA 切换
- [ ] **全屏模式** — 隐藏地址栏和导航按钮，最大化内容区
- [ ] **网络状态** — 连接状态指示（表盘边缘颜色）
- [ ] **下载管理** — 文件下载进度和管理
- [ ] **安全提示** — HTTPS 锁图标，证书错误警告

### P3 — 表盘特有

- [ ] **表冠交互** — 旋转表冠滚动页面
- [ ] **手势导航** — 从边缘滑入返回上一页
- [ ] **省电模式** — 降低刷新率，暗色主题
- [ ] **快速启动表盘** — 作为 watch face complication 快速打开

## 交互设计备注

| touchweb 交互 | watchweb 适配方案 |
|---------------|-------------------|
| 标签栏 (顶部横排) | 表冠旋转切换 + 边缘弧形点指示 |
| 右键菜单 | 长按弹出圆形径向菜单 |
| 工具栏 (底部横排) | 底部三按钮 + 手势补充 |
| 设置页 (全屏列表) | 垂直滚动圆形裁剪列表 |
| 收藏夹管理 | 九宫格快速拨号 (3x3) |
| 历史记录 | 时间线垂直列表 |
