# WatchWeb 功能开发计划

> 基于 touchweb 功能集，适配 480x480 圆形表盘交互

## 已完成

- [x] 网页加载/渲染 (Agave 引擎集成)
- [x] 前进/后退/刷新导航
- [x] 弧形加载进度指示
- [x] 全屏内容区 — 去地址栏，内容充满 480x480（圆屏硬件裁剪）
- [x] 导航栏悬浮化 — 默认隐藏，底部 FAB 图标点击从底部弹出
- [x] 触摸拖拽滚动 — tile buffer 平移（惯性衰减待做）
- [x] 单击转发点击事件到引擎

### 工程稳定性 / 适配（本轮）

- [x] QuickJS DOM wrapper UAF 根治 — 弱引用缓存 + 借用引用 dup
- [x] 引擎滚动条禁用 — scrollbar_width=0，适配 tile buffer
- [x] 480 移动浏览器视口 — minimum_layout_size 钉 480，响应式站走移动布局
- [x] needsLayout 崩溃修复 — invalidate 只标脏，paint 由 update_view_now 驱动
- [x] 内存安全 — buffer 分配检查；canvas buffer 生命周期归属
- [x] 渲染线程方案设计文档 (docs/render-thread-design.md)

## 待开发

### P0 — 核心体验

- [ ] **滚动惯性** — 触摸拖拽滚动 + 惯性衰减动画（拖拽已实现，缺惯性）
- [ ] **缩放手势** — 双指捏合缩放，双击放大（setZoom 已实现，缺手势）
- [ ] **搜索引擎** — 输入非 URL 时自动搜索（地址栏已移除，需新入口）
- [ ] **长按菜单** — 链接/图片长按弹出操作菜单（圆形弧形菜单）

### P1 — 功能完整

- [ ] **多标签页** — 表冠旋转切换标签，边缘弧形标签指示器
- [ ] **历史记录** — SQLite 存储，列表页面（垂直滚动）
- [ ] **收藏夹** — 添加/管理收藏，快速拨号页
- [ ] **表单自动填充** — 记住用户名密码，自动填入

### P2 — 增强功能

- [ ] **设置页面** — 字体大小、缩放比例、清除数据、UA 切换
- [x] **全屏模式** — 已实现：内容区充满全屏，导航悬浮可隐藏
- [ ] **网络状态** — 连接状态指示（表盘边缘颜色）
- [ ] **下载管理** — 文件下载进度和管理
- [ ] **安全提示** — HTTPS 锁图标，证书错误警告

### P4 — 内存/性能优化（代码审查后续）

- [ ] **tile buffer 瘦身** — 去横向余量 5.5MB→2.7MB（需重验 buffer=480 不崩）
- [ ] **自定义 webview widget** — DRAW_MAIN 直接画 tile buffer，省 canvas 0.9MB + 一次拷贝
- [ ] **字体按需加载** — 仅加载页面用到的字形，省 3-4MB
- [ ] **渲染线程模式** — 见 docs/render-thread-design.md
- [ ] **死代码清理** — mouseMove / m_engine_repaint / 未用 getter

### P3 — 表盘特有

- [ ] **表冠交互** — 旋转表冠滚动页面
- [ ] **手势导航** — 从边缘滑入返回上一页
- [ ] **省电模式** — 降低刷新率，暗色主题
- [ ] **快速启动表盘** — 作为 watch face complication 快速打开

## 交互设计备注

| touchweb 交互 | watchweb 适配方案 |
|---------------|-------------------|
| 标签栏 (顶部横排) | 表冠旋转切换 + 边缘弧形点指示 |
| 右键菜单 | 长按弹出圆形径向菜单 |
| 工具栏 (底部横排) | 底部三按钮 + 手势补充 |
| 设置页 (全屏列表) | 垂直滚动圆形裁剪列表 |
| 收藏夹管理 | 九宫格快速拨号 (3x3) |
| 历史记录 | 时间线垂直列表 |
